## Recording rules

- Replace **Not run** with **Pass**, **Fail**, **Blocked**, or **N/A**. Explain Blocked/N/A in Notes.
- Local and hosted are separate runs. Do not copy Pass automatically between columns.
- Record the tester and fixture/reference. Put the failure report or evidence filename/link in Notes.
- For a case containing multiple forms/devices, list the variants tested. Mark Blocked/Fail if a required variant remains untested/fails; do not report an incomplete case as a full Pass.
- Use a separate copy for another release/run. Preserve previous failures and retest results.
- Never include passwords, Authorization headers, JWTs, card information, or real personal documents.
